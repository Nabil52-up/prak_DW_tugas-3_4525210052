# Profil Mahasiswa

## Deskripsi

Project ini dibuat untuk praktikum Pertemuan 03 tentang pengenalan CSS. Pada tugas ini, saya membuat halaman profil mahasiswa menggunakan HTML dan CSS.

Tampilan halaman dibuat seperti Curriculum Vitae (CV) dengan menggunakan **CSS internal**. Semua kode CSS ditulis di dalam tag `<style>` pada file HTML. CSS digunakan untuk mengatur warna, ukuran teks, jarak, tata letak, border, dan tampilan gambar.

## Mini Style Guide

### Opsi A (Digunakan pada Halaman)

**Font**
- Font utama: Arial, Helvetica, sans-serif
- Ukuran teks utama: 16px
- Ukuran teks Tentang Saya: 17px
- Ukuran judul utama (H1): 36px
- Ukuran subjudul (H2): 24px

**Warna**
- Warna utama: `#FFC107` (kuning) dan `#0F382B` (hijau tua)
- Warna tambahan: `rgb(0, 102, 153)` (biru)
- Warna teks: `#333333`
- Warna footer: gradasi hijau tua ke biru

**Jarak**
- Padding header: `30px 20px`
- Padding konten utama: `20px 30px`
- Margin konten utama: `30px auto`
- Line-height halaman: `1.6`
- Line-height Tentang Saya: `1.8`
- Line-height daftar keahlian: `2`

**Tampilan**
- Sudut foto membulat: `12px`
- Border foto: `4px solid #0F382B`
- Border judul: `2px solid rgb(0, 102, 153)`
- Background header: gradasi kuning
- Background halaman: `#F4F4F4`

## Format Warna CSS

Dalam CSS, warna bisa ditulis dengan beberapa format, seperti berikut:

```css
/* HEX */
#FFC107

/* RGB */
rgb(0, 102, 153)

/* RGBA */
rgba(0, 102, 153, 0.15)

/* HSL */
hsl(163, 62%, 14%)
```
